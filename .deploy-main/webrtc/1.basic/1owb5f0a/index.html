WebRTC 媒体轨道完全指南

RTCRtpSender、RTCRtpReceiver、RTCRtpTransceiver、RTCTrackEvent

概述

媒体轨道模块包含 WebRTC 中处理音视频轨道的核心接口：

接口职责
RTCRtpSender编码和发送本地轨道
RTCRtpReceiver接收和解码远端轨道
RTCRtpTransceiverSender + Receiver 配对，代表一个媒体方向
RTCTrackEvent新轨道添加时触发的事件

关系图：

┌─────────────────────────────────────────────────────────────┐
│                    RTCPeerConnection                         │
│                                                             │
│   ┌──────────────────┐      ┌──────────────────┐          │
│   │ RTCRtpTransceiver │      │ RTCRtpTransceiver │          │
│   ├──────────────────┤      ├──────────────────┤          │
│   │ sender           │      │ sender           │          │
│   │ receiver         │      │ receiver         │          │
│   │ mid = "0"        │      │ mid = "1"        │          │
│   └──────────────────┘      └──────────────────┘          │
│          │                         │                       │
│          ▼                         ▼                       │
│   ┌─────────────┐           ┌─────────────┐                │
│   │ RTCRtpSender│           │ RTCRtpSender│                │

RTCRtpSender

发送器接口

属性

属性类型说明
trackMediaStreamTrack | null当前发送的轨道
transportRTCDtlsTransportDTLS 传输层
dtmfRTCDTMFSender | nullDTMF 发送器（仅音频）
transformRTCRtpScriptTransform帧变换管道（实验性）

静态方法

getCapabilities(kind)

返回系统发送指定类型媒体的能力。

RTCRtpSender.getCapabilities('audio')  // RTCRtpCapabilities | null
RTCRtpSender.getCapabilities('video')  // RTCRtpCapabilities | null

实例方法

方法说明
getParameters()获取当前编码和传输配置
setParameters(params)更新编码和传输参数
getStats()获取统计报告
setStreams(stream)设置关联的 MediaStream
replaceTrack(track)替换发送轨道（不断开连接）

使用示例

// 添加轨道
const videoTrack = await navigator.mediaDevices.getUserMedia({ video: true });
const sender = pc.addTrack(videoTrack, stream);

// 切换摄像头
const newCamera = await navigator.mediaDevices.getUserMedia({ video: { facingMode: 'environment' } });
await sender.replaceTrack(newCamera.getVideoTracks()[0]);

// 使用 Transform
const worker = new Worker("transform-worker.js");
sender.transform = new RTCRtpScriptTransform(worker, { name: "senderTransform" });

RTCRtpReceiver

接收器接口

属性

属性类型说明
trackMediaStreamTrack当前接收的轨道
transportRTCDtlsTransportDTLS 传输层
jitterBufferTargetDOMHighResTimeStamp抖动缓冲目标（实验性）
transformRTCRtpScriptTransform帧变换管道（实验性）

静态方法

getCapabilities(kind)

返回系统接收指定类型媒体的能力。

RTCRtpReceiver.getCapabilities('audio')  // RTCRtpCapabilities | null
RTCRtpReceiver.getCapabilities('video')  // RTCRtpCapabilities | null

实例方法

方法说明
getParameters()获取解码参数
getStats()获取统计报告
getContributingSources()获取 CSRC 源列表
getSynchronizationSources()获取 SSRC 源列表

使用示例

// 获取所有接收器
const receivers = pc.getReceivers();

receivers.forEach((receiver) => {
  console.log('轨道类型:', receiver.track.kind);
  console.log('传输:', receiver.transport);
});

// 使用 Transform 处理接收帧
const worker = new Worker('transform-worker.js');
receiver.transform = new RTCRtpScriptTransform(worker, { operation: 'decode-video' });

RTCRtpTransceiver

收发器接口（Sender + Receiver 配对）

属性

属性类型说明
midstring | null媒体标识符（关联后非空）
senderRTCRtpSender发送器
receiverRTCRtpReceiver接收器
directionstring期望方向
currentDirectionstring | null当前协商方向

方向值

值说明
sendrecv发送并接收
sendonly仅发送
recvonly仅接收
inactive不发送也不接收

方向状态机

sendrecv ◄─────────────────────────────► sendrecv
    │
    ▼
recvonly ◄─────────────────────────────► recvonly
    │
    ▼
sendonly
    │
    ▼
inactive

方法

方法说明
stop()永久停止 transceiver
setCodecPreferences(codecs)设置优先编解码器列表

transceiver 与 m-line 关系

SDP 媒体段落                 RTCRtpTransceiver
┌─────────────────┐          ┌─────────────────┐
│ m=video 9 ...   │          │ mid: "0"        │
│ a=mid:0         │◄────────►│ sender          │
└─────────────────┘          │ receiver        │
                              └─────────────────┘

使用示例

// addTrack 自动创建 transceiver
pc.addTrack(track, stream);

// 或显式创建
pc.addTransceiver("audio");

// 修改方向
const [transceiver] = pc.getTransceivers();
transceiver.direction = "recvonly";

// 停止
transceiver.stop();

// 设置编解码器偏好
const codecs = RTCRtpSender.getCapabilities("video").codecs;
const vp9Codecs = codecs.filter(c => c.mimeType === "video/VP9");
transceiver.setCodecPreferences(vp9Codecs);

RTCTrackEvent

轨道事件

触发时机

当新的 MediaStreamTrack 被添加到 RTCRtpReceiver 时触发。

属性

属性类型说明
receiverRTCRtpReceiver接收器
trackMediaStreamTrack新添加的轨道
streamsMediaStream[]所属的媒体流数组
transceiverRTCRtpTransceiver关联的收发器

使用示例

pc.ontrack = (event) => {
  const { track, streams, receiver, transceiver } = event;
  
  // 将轨道添加到视频元素
  const videoElement = document.getElementById("video-box");
  videoElement.srcObject = streams[0];
  
  console.log('轨道类型:', track.kind);  // "audio" 或 "video"
};

完整流程示例

添加本地轨道

// 获取本地媒体
const localStream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });

// 添加到连接
const videoTrack = localStream.getVideoTracks()[0];
const audioTrack = localStream.getAudioTracks()[0];

pc.addTrack(videoTrack, localStream);
pc.addTrack(audioTrack, localStream);

接收远端轨道

pc.ontrack = (event) => {
  const remoteStream = event.streams[0];
  const remoteVideo = document.getElementById('remote-video');
  
  // 检查是音频还是视频轨道
  if (event.track.kind === 'video') {
    remoteVideo.srcObject = remoteStream;
  }
};

替换轨道

// 切换前置/后置摄像头
const newCamera = await navigator.mediaDevices.getUserMedia({ 
  video: { facingMode: 'environment' } 
});

const videoSender = pc.getSenders().find(s => s.track?.kind === 'video');
await videoSender.replaceTrack(newCamera.getVideoTracks()[0]);

Simulcast 3 层发流（SFU 场景必用）

每个 m= 行对应一个 RTCRtpTransceiver，一个 Transceiver 恰好有一个 .sender + 一个 .receiver。

RTCRtpTransceiver
  ├─ .mid / .currentDirection  只读协商结果
  ├─ .direction                可读可写（改了会触发 negotiationneeded）
  │       : sendrecv | sendonly | recvonly | inactive | stopped
  ├─ .sender / .receiver       一对固定关联
  ├─ setCodecPreferences(RTCRtpCodecCapability[])  // 指定偏好的编码顺序（如 VP9 > VP8）
  └─ stop()   // 永久停用：该 m= 行 port=0，后续 SDP 不再谈它

RTCRtpSender
  ├─ .track / .rtcp / .transport / .dtmf / .transform  只读
  ├─ getParameters()            → RTCRtpSendParameters
  ├─ setParameters(params)      → Promise<void>    // 改 maxBitrate / scaleResolutionDownBy / active
  ├─ replaceTrack(track|null)   → Promise<void>    // 切摄像头/切屏幕/静音黑帧，无需重协商！
  ├─ setStreams(...streams)                        // 改 track 属于哪些 MediaStream（不改 RTP）
  └─ getStats()

RTCRtpReceiver
  ├─ .track / .transport / .transform / .jitterBufferTarget
  ├─ getParameters()
  ├─ getSynchronizationSources()   // 最近 10s 内收到的 SSRC 列表 + 音频电平 audioLevel
  ├─ getContributingSources()      // 混音入参与的 CSRC（多人会议贡献源）
  └─ getStats()

Simulcast 3 层发流示例：

pc.addTransceiver(videoTrack, {
  direction: 'sendrecv',
  sendEncodings: [
    { rid: 'f', maxBitrate: 2_500_000, scaleResolutionDownBy: 1, dtx: false }, // 1080p
    { rid: 'h', maxBitrate:   700_000, scaleResolutionDownBy: 2 },              //  540p
    { rid: 'q', maxBitrate:   200_000, scaleResolutionDownBy: 4 },              //  270p
  ],
});
