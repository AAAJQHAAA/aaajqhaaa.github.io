# 使用 PeerJS 构建网络电话

- https://peerjs.com/ - 简化 WebRTC 的库

## PeerJS 

| 部分 | 说明 |
|------|------|
| 客户端框架 | 简化 WebRTC 调用 |
| 服务器 | 提供信令和穿透服务 |

```
PeerJS Cloud Server = 信令服务器 + STUN/TURN 服务器

1. 提供信令：帮双方交换 SDP
2. 提供穿透：帮双方建立直连（或中继）
```

## 一、项目初始化

### 1. 创建项目目录

```bash
mkdir audio_app
cd audio_app
yarn init
```

### 2. 安装依赖

```bash
yarn add express    # Web 服务器
yarn add peerjs      # 客户端框架
yarn add peer        # PeerJS 服务器
```

### 3. package.json 配置

```json
{
  "name": "audio_app",
  "scripts": {
    "start": "node server.js"
  },
  "dependencies": {
    "express": "^4.17.1",
    "peer": "^0.5.3",
    "peerjs": "^1.3.1"
  }
}
```

### 4. HTML 页面

```html
<body>
  <h1>Phone a friend</h1>
  <p id="status">Connecting...</p>
  <button class="call-btn">Call</button>

  <!-- 通话界面 -->

  <!-- 输入对方 ID -->
  <section class="modal" hidden>
    <input placeholder="Enter friend's device ID" />

</body>
```

### 5. 引入 PeerJS

```html
<script src="https://unpkg.com/peerjs@1.3.1/dist/peerjs.min.js"></script>
```

## 二、构建服务器

### 完整服务器代码

```js
const express = require("express");
const http = require("http");
const path = require("path");
const { ExpressPeerServer } = require("peer");

const app = express();
const server = http.createServer(app);
const port = process.env.PORT || "8000";

// 创建 PeerJS 服务器
const peerServer = ExpressPeerServer(server, {
  proxied: true,
  debug: true,
  path: "/myapp",
});

app.use(peerServer);  // 使用 PeerJS
app.use(express.static(path.join(__dirname)));  // 静态文件
app.get("/", (req, res) => res.sendFile(`${__dirname}/index.html`));

server.listen(port);
```

### 关键点

| 要点 | 说明 |
|------|------|
| `ExpressPeerServer` | PeerJS 提供的信令服务器 |
| `proxied: true` | 放在代理后面时开启 |
| `path: "/myapp"` | PeerJS 连接路径 |

### 启动服务

```bash
yarn start
# 访问 http://localhost:8000
```

## 三、客户端代码

### 1. 初始化 Peer 对象

```js
const peer = new Peer(
  `${Math.floor(Math.random() * 2 ** 18).toString(36).padStart(4, 0)}`,
  {
    host: location.hostname,
    debug: 1,
    path: "/myapp",
  }
);

window.peer = peer;  // 挂载到 window
```

### 2. 获取麦克风权限

```js
function getLocalStream() {
  navigator.mediaDevices
    .getUserMedia({ video: false, audio: true })
    .then((stream) => {
      window.localStream = stream;           // 保存流
      window.localAudio.srcObject = stream;  // 本地播放
      window.localAudio.autoplay = true;
    })
    .catch((err) => {
      console.error(`错误: ${err}`);
    });
}

getLocalStream();
```

### 3. 显示设备 ID

```js
peer.on("open", () => {
  document.getElementById("cast-status").textContent =
    `Your device ID is: ${peer.id}`;
});
```

### 4. 切换界面函数

```js
const audioContainer = document.querySelector(".call-container");

// 显示呼叫按钮
function showCallContent() {
  document.getElementById("cast-status").textContent = `Your device ID is: ${peer.id}`;
  callBtn.hidden = false;
  audioContainer.hidden = true;
}

// 显示通话界面
function showConnectedContent() {
  document.getElementById("cast-status").textContent = "You're connected";
  callBtn.hidden = true;
  audioContainer.hidden = false;
}
```

### 5. 获取对方 ID

```js
let code;
function getStreamCode() {
  code = window.prompt("请输入对方的设备 ID");
}
```

### 6. 建立连接

```js
let conn;
function connectPeers() {
  conn = peer.connect(code);
}

// 对方收到连接请求
peer.on("connection", (connection) => {
  conn = connection;
});
```

### 7. 发起呼叫

```js
const callBtn = document.querySelector(".call-btn");

callBtn.addEventListener("click", () => {
  getStreamCode();      // 获取对方 ID
  connectPeers();       // 建立连接

  // 发起呼叫
  const call = peer.call(code, window.localStream);

  // 收到对方音频流
  call.on("stream", (stream) => {
    window.remoteAudio.srcObject = stream;  // 播放对方声音
    showConnectedContent();                  // 显示通话界面
  });
});
```

### 8. 接听来电

```js
peer.on("call", (call) => {
  const answerCall = confirm("是否接听？");

  if (answerCall) {
    call.answer(window.localStream);  // 接听并发送本地音频
    showConnectedContent();

    // 收到对方音频流
    call.on("stream", (stream) => {
      window.remoteAudio.srcObject = stream;
    });
  } else {
    console.log("拒接来电");
  }
});
```

### 9. 结束通话

```js
const hangUpBtn = document.querySelector(".hangup-btn");
hangUpBtn.addEventListener("click", () => {
  conn.close();       // 关闭连接
  showCallContent();  // 恢复初始界面
});

// 对方也更新界面
conn.on("close", () => {
  showCallContent();
});
```

## 四、完整流程

```
1. 初始化 Peer
2. 获取麦克风权限
3. 显示自己的设备 ID
4. 对方输入你的 ID，发起呼叫
5. 你收到来电，确认接听
6. 双方通话
7. 任意一方挂断
```

## 五、PeerJS vs 原生 WebRTC

| 对比 | 原生 WebRTC | PeerJS |
|------|-------------|--------|
| 信令 | 需要自己实现 | 服务器提供 |
| ICE | 需要手动处理 | 自动处理 |
| 代码量 | 多 | 少 |
| 灵活性 | 高 | 低 |

---

## 六、总结

**PeerJS 让 WebRTC 变得简单**：
- 自动处理信令和 ICE
- 10 行代码就能打电话
- 适合快速原型开发
