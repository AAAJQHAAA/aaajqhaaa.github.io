# WebRTC 使用的编解码器

## 一句话理解

**编解码器** = 音视频的"翻译官"，负责压缩/解压数据。协商一致才能通话。

## 必选编解码器（所有浏览器必须支持）

| 类型 | 编解码器 | 用途 |
|------|---------|------|
| 视频 | VP8、H.264 | 视频压缩 |
| 音频 | Opus | 高质量音频（推荐） |
| 音频 | G.711 | 传统电话音质 |

## 视频编解码器对比

| 编解码器 | 兼容性 | 特点 |
|---------|--------|------|
| **VP8** | 所有浏览器 | 必选，启动快 |
| **H.264** | 主流浏览器 | 必选，iOS 硬件支持好 |
| **VP9** | Chrome、Firefox | 高质量，兼容性差 |
| **AV1** | 新版浏览器 | 最高质量，但新 |

**推荐**：VP8 + H.264 双保险

## 音频编解码器对比

| 编解码器 | 兼容性 | 比特率 |
|---------|--------|--------|
| **Opus** | 所有浏览器 | 8-128 kbps（推荐） |
| **G.711** | 所有浏览器 | 64 kbps（电话音质） |

## 快速选择

| 场景 | 推荐 |
|------|------|
| 跨平台兼容 | VP8 + Opus |
| iOS 设备 | H.264 + Opus |
| 最高质量 | AV1（兼容性差） |
| 最低延迟 | VP8 + Opus |

## 技术参数

- 视频分辨率：最低 320×240
- 帧率：最低 20 FPS
- Opus 推荐：语音 8-20 kbps，音乐 48-128 kbps
