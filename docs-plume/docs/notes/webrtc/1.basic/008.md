## WebRTC DTMF 功能

- 实际没啥用

DTMF（双音多频）就是电话上的"按键音"。

### WebRTC DTMF 的限制

| 功能 | 支持情况 |
|------|---------|
| 发送 DTMF | 支持 |
| 接收 DTMF | **不支持**，WebRTC 会忽略 |

### 应用场景

| 场景 | 说明 |
|------|------|
| 电话会议 | 输入会议室号码 |
| 菜单导航 | "请按 1 转销售，按 2 转技术" |
| 语音信箱 | 输入密码查看 |
| 支付验证 | 输入信用卡号 |

---

## 工作原理

```
DTMF 不走音频通道！
        ↓
通过 RTP payload 单独发送
        ↓
对方收到后... 实际上 WebRTC 会忽略
```

**注意**：DTMF 是**带外传输**的，不影响正常音频。

---

## 发送 DTMF

### 核心代码

```js
// 1. 获取 RTCDTMFSender
const dtmfSender = pc.getSenders()[0].dtmf;

// 2. 发送 DTMF
dtmfSender.insertDTMF("1234#5678");

// 3. 监听发送完成
dtmfSender.ontonechange = (event) => {
  if (event.tone === "") {
    console.log("发送完成");
  }
};
```

---

## insertDTMF 参数

| 参数 | 说明 |
|------|------|
| tones | DTMF 字符串，如 "1234567890*#" |
| duration | 每个音的时长（ms），默认 100 |
| interToneGap | 音之间的间隔（ms），默认 70 |

### 示例

```js
// 发送 "1-2-3"，每个音 200ms，间隔 100ms
dtmfSender.insertDTMF("123", { duration: 200, interToneGap: 100 });
```

## 实际应用场景

### 电话会议

```js
// 连接会议室后，输入会议号
dtmfSender.insertDTMF("12345678");  // 会议号
dtmfSender.insertDTMF("#");          // 确认
```

### IVR 菜单导航

```js
// "按 1 转销售"
dtmfSender.insertDTMF("1");

// 等待语音播报后
dtmfSender.insertDTMF("分机号#");
```

---

## 重要提醒

1. **对方收不到** - WebRTC 目前无法接收 DTMF
2. **不是音频** - 不会在对方扬声器播放为声音
3. **兼容性** - 现代浏览器都支持

---

## 总结

DTMF 在 WebRTC 中**用得很少**，主要因为：
- 无法接收对方发送的 DTMF
- 实际电话系统中 DTMF 通常通过 SIP 信令传输

**结论**：普通视频通话不需要了解这个功能。
