# WebRTC 数据通道完全指南

> RTCDataChannel、RTCDataChannelEvent、RTCDataChannelStats

---

## 概述

`RTCDataChannel` 提供双向 peer-to-peer 数据传输通道。

**特点**：
- 每个 `RTCPeerConnection` 最多可拥有 65,534 个数据通道
- 可传输任意数据（字符串、Blob、ArrayBuffer 等）
- 基于 SCTP over DTLS 传输协议

**与 WebSocket 对比**：

| 特性 | RTCDataChannel | WebSocket |
|------|---------------|-----------|
| 延迟 | 极低 | 低 |
| 复杂度 | 高（需ICE/STUN/TURN） | 低 |
| 适用场景 | 游戏/实时控制 | 常规通信 |

## RTCDataChannel

> 数据通道接口

### 创建方式

```js
// 主动创建
const dc = pc.createDataChannel('chat');

// 被动接收
pc.ondatachannel = (event) => {
  const dc = event.channel;
};
```

### 状态机

```
connecting → open ↔ closing → closed
                ↓
            (错误)
```

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `binaryType` | string | 接收的二进制类型：`"arraybuffer"` 或 `"blob"` |
| `bufferedAmount` | number | 缓冲数据量（字节） |
| `bufferedAmountLowThreshold` | number | 缓冲低阈值 |
| `id` | number | 通道 ID（0 ~ 65534） |
| `label` | string | 通道名称 |
| `ordered` | boolean | 是否有序传输（默认 true） |
| `maxPacketLifeTime` | number | 最大数据包生存时间（毫秒） |
| `maxRetransmits` | number | 最大重传次数 |
| `negotiated` | boolean | 是否应用协商（默认 false） |
| `priority` | string | 优先级：`"very-low"` / `"low"` / `"medium"` / `"high"` |
| `protocol` | string | 子协议名称 |
| `readyState` | string | 连接状态 |

### 可靠性矩阵（3 × 2 = 6 种常用语义）

| ordered | maxRetransmits | maxPacketLifeTime | 典型用途 |
|---|---|---|---|
| ✅ true | 不传 | 不传 | **可靠有序**（默认），类似 WebSocket TCP 式 |
| ✅ true | 0 | - | 有序+尽力（丢了就丢，不重传，顺序不乱） |
| ✅ true | N | - | 有序+最多重传 N 次后放弃 |
| ❌ false | 不传 | 不传 | 可靠但无序（每包独立确认，只要到就推应用） |
| ❌ false | 0 | - | **完全无序尽力而为**，类似 UDP（游戏同步状态、体感数据） |
| ❌ false | N / ms | N / ms | 无序+部分可靠，窗口内重传（实时文件传输的高速块） |

### 方法

#### send() — 发送数据

```js
dc.send(data);
```

**参数**：`data` 可为字符串、Blob、ArrayBuffer、TypedArray 或 DataView

**异常**：
- `InvalidStateError`：通道状态为 `connecting`
- `OperationError`：缓冲区已满

#### close() — 关闭通道

```js
dc.close();
```

**关闭流程**：
1. `readyState` 变为 `closing`
2. 处理缓冲消息
3. 关闭底层传输
4. `readyState` 变为 `closed`
5. 触发 `close` 事件

### 事件

| 事件 | 触发时机 |
|------|----------|
| `open` | 通道首次打开或重新打开 |
| `message` | 收到远程消息 |
| `bufferedamountlow` | 缓冲区数据量低于阈值 |
| `close` | 底层传输关闭 |
| `closing` | 底层传输开始关闭前 |
| `error` | 发生错误 |

### 使用示例

```js
// 建立连接
const dc = pc.createDataChannel('chat');

// 监听打开
dc.onopen = () => {
  console.log('通道已打开');
  dc.send('Hello!');
};

// 监听消息
dc.onmessage = (event) => {
  console.log('收到:', event.data);
};

// 发送各种类型数据
dc.send('字符串');
dc.send(arrayBuffer);
dc.send(blob);

// 关闭
dc.close();
```

## RTCDataChannelEvent

> 数据通道事件

**触发时机**：远程对等端创建数据通道时。

### 构造函数

```js
new RTCDataChannelEvent(type, options)
```

**options**：
| 属性 | 说明 |
|------|------|
| `channel` | 关联的 RTCDataChannel 对象 |

### 属性

| 属性 | 说明 |
|------|------|
| `channel` | 关联的 RTCDataChannel 对象 |

### 使用示例

```js
pc.ondatachannel = (event) => {
  const inboundDataChannel = event.channel;
  inboundDataChannel.onmessage = handleIncomingMessage;
  inboundDataChannel.onopen = handleChannelOpen;
  inboundDataChannel.onclose = handleChannelClose;
};
```

## RTCDataChannelStats

> 数据通道统计

**获取方式**：`RTCPeerConnection.getStats()` 中 `type` 为 `"data-channel"` 的条目。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `bytesSent` | number | 已发送字节数 |
| `bytesReceived` | number | 已接收字节数 |
| `messagesSent` | number | 已发送消息数 |
| `messagesReceived` | number | 已接收消息数 |
| `dataChannelIdentifier` | number | 关联的通道 ID |
| `label` | string | 通道名称 |
| `protocol` | string | 子协议 |
| `state` | string | 通道状态 |

### 使用示例

```js
const stats = await pc.getStats();

stats.forEach((report) => {
  if (report.type === "data-channel" && report.dataChannelIdentifier === dc.id) {
    console.log('已发送:', report.bytesSent, '字节');
    console.log('已接收:', report.bytesReceived, '字节');
    console.log('消息数:', report.messagesSent);
  }
});
```

## 完整示例

```js
// 创建数据通道
const dc = pc.createDataChannel('chat', {
  ordered: true,           // 保证有序
  maxRetransmits: 3        // 最多重传3次
});

// 发送端
dc.onopen = () => {
  console.log('通道打开');
  dc.send('Hello!');

  // 监测缓冲区
  setInterval(() => {
    console.log('缓冲:', dc.bufferedAmount, '字节');
  }, 1000);
};

// 接收端
pc.ondatachannel = (event) => {
  const rcvChannel = event.channel;
  rcvChannel.onmessage = (event) => {
    console.log('收到:', event.data);
  };
};

// 错误处理
dc.onerror = (error) => {
  console.error('通道错误:', error);
};
```
