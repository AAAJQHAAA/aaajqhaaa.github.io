# WebRTC 统计完全指南

> RTCStatsReport 及相关统计接口

---

## 概述

WebRTC 统计 API 用于监控连接质量、音视频性能等关键指标。

**核心接口**：

| 接口 | 说明 |
|------|------|
| `RTCStatsReport` | 统计报告容器，类似只读 Map |
| `RTPStreamStats` | RTP 流统计（Inbound/Outbound/Remote） |
| `RTCCodecStats` | 编解码器统计 |
| `RTCCertificateStats` | DTLS 证书统计 |
| `RTCTransportStats` | 传输层统计 |
| `RTCAudioSourceStats` | 音频源统计 |
| `RTCVideoSourceStats` | 视频源统计 |

---

## 获取统计

### 基本方法

```js
// 通过 RTCPeerConnection 获取
const stats = await peerConnection.getStats();

// 通过单个 sender/receiver 获取
const stats = await sender.getStats();
```

### RTCStatsReport 结构

```js
// 类似只读 Map
stats.size                    // 统计条目数量
stats.get(id)                 // 获取指定 ID 的统计
stats.has(id)                 // 检查是否存在
stats.forEach(fn)             // 遍历所有
stats.entries()               // [id, stats] 键值对
```

### 11 大类 stats.type switch case

```ts
const report: RTCStatsReport = await pc.getStats();   // Map<string, RTCStats>
for (const [id, stats] of report) {
  switch (stats.type) {
    case "outbound-rtp":       // 发送端：看 packetsSent / bytesSent / framesEncoded
    case "inbound-rtp":        // 接收端：看 packetsReceived / packetsLost / jitter / framesDecoded / framesDropped
    case "remote-inbound-rtp": // 对端 RTCP 反馈：fractionLost / jitter / roundTripTime（从 RTCP RR/SR 解）
    case "remote-outbound-rtp":
    case "candidate-pair":     // 选中的候选对：currentRoundTripTime / nominated / bytesSent / bytesReceived
                               //    还要看 .state = "in-progress" | "succeeded" | "failed" 等
    case "local-candidate"   | "remote-candidate":
    case "transport":          // bytesSent / bytesReceived / dtlsState / selectedCandidatePairId
    case "sctp-transport":     // DATA_CHANNEL_OPEN / COMMON_UP / COMMON_DOWN ...
    case "data-channel":       // messagesSent / messagesReceived / bytesSent / bytesReceived / state
    case "codec":              // mimeType / clockRate / channels / sdpFmtpLine
    case "media-source":       // trackId / framesPerSecond / width / height（采集源侧）
    case "media-playout":      // kind / jitterBufferEmittedCount / playoutCount（渲染侧）
    case "peer-connection":    // dataChannelsOpened / dataChannelsClosed 总计数
  }
}
```

## RTP 流统计 — RTPStreamStats

> Inbound / Outbound / RemoteInbound / RemoteOutbound

### 流向关系图

```
┌─────────────────────────────────────────────────────────────┐
│                        本地 RTCPeerConnection                │
│                                                             │
│   发送端                                                      │
│   ┌──────────────┐      outbound-rtp ──→ 远端              │
│   │ RTCRtpSender │                                         │
│   └──────────────┘                                         │
│         ↓                                                   │
│   inbound-rtp ◄── (远端发送的统计)                          │
│                                                             │
│   接收端                                                      │
│   ┌──────────────┐      outbound-rtp ──→ 远端              │
│   │ RTCRtpReceiver│─── remote-outbound-rtp                  │
│   └──────────────┘                                         │
│         ↓                                                   │
│   inbound-rtp (本地接收)                                     │
└─────────────────────────────────────────────────────────────┘
```

### 四种 RTP 流统计对比

| 类型 | 说明 | 用途 |
|------|------|------|
| `RTCInboundRtpStreamStats` | 本地接收的 RTP 流 | 监控本地收到的音视频质量 |
| `RTCOutboundRtpStreamStats` | 本地发送的 RTP 流 | 监控本地发送的音视频质量 |
| `RTCRemoteInboundRtpStreamStats` | 远端接收的 RTP 流 | 计算往返时间 RTT |
| `RTCRemoteOutboundRtpStreamStats` | 远端发送的 RTP 流 | 监控远端发送的音视频质量 |

### 公共属性

| 属性 | 说明 |
|------|------|
| `id` | 统计对象唯一标识符 |
| `timestamp` | 采样时间戳 |
| `type` | 统计类型 |
| `ssrc` | 同步源标识符 |
| `kind` | `"audio"` 或 `"video"` |
| `mediaType` | 媒体类型（已废弃，用 `kind`） |

### 接收统计（Inbound）

**RTCInboundRtpStreamStats** 包含：

| 属性 | 说明 |
|------|------|
| `bytesReceived` | 接收字节数 |
| `packetsReceived` | 接收数据包数 |
| `packetsLost` | 丢失的数据包数 |
| `jitter` | 抖动（秒） |
| `roundTripTime` | 往返时间（秒） |
| `packetsDiscarded` | 丢弃的数据包数 |
| `fecPacketsReceived` | 收到的 FEC 包数 |
| `fecPacketsDiscarded` | 丢弃的 FEC 包数 |
| `frameWidth` / `frameHeight` | 视频宽/高 |
| `framesReceived` | 收到的帧数 |
| ` framesDecoded` | 解码的帧数 |
| `audioLevel` | 音频电平（0~1） |

### 发送统计（Outbound）

**RTCOutboundRtpStreamStats** 包含：

| 属性 | 说明 |
|------|------|
| `bytesSent` | 发送字节数 |
| `packetsSent` | 发送数据包数 |
| `retransmittedPacketsSent` | 重传的包数 |
| `retransmittedBytesSent` | 重传的字节数 |
| `targetBitrate` | 目标码率（bps） |
| `framesEncoded` | 编码的帧数 |
| `frameWidth` / `frameHeight` | 视频宽/高 |
| `framesPerSecond` | 帧率 |

### 远程统计（Remote）

**RTCRemoteInboundRtpStreamStats** 包含：

| 属性 | 说明 |
|------|------|
| `roundTripTime` | 往返时间 |
| `packetsLost` | 远端记录的丢包数 |
| `fractionLost` | 丢包率（0~1） |

**RTCRemoteOutboundRtpStreamStats** 包含：

| 属性 | 说明 |
|------|------|
| `bytesSent` | 远端发送的字节数 |
| `packetsSent` | 远端发送的数据包数 |
| `roundTripTime` | 往返时间 |

### 计算网络质量

```js
const stats = await peerConnection.getStats();

stats.forEach(report => {
  if (report.type === 'inbound-rtp' && report.kind === 'video') {
    // 丢包率
    const packetsLost = report.packetsLost;
    const packetsReceived = report.packetsReceived;
    const lossRate = packetsLost / (packetsLost + packetsReceived);
    
    // 抖动
    const jitterMs = report.jitter * 1000;
    
    // RTT（需配合 remote-inbound-rtp）
    console.log(`丢包率: ${(lossRate * 100).toFixed(2)}%`);
    console.log(`抖动: ${jitterMs.toFixed(2)}ms`);
  }
});
```

## 编解码器统计 — RTCCodecStats

通过 `codecId` 与 RTP 流统计关联。

| 属性 | 类型 | 说明 |
|------|------|------|
| `mimeType` | string | MIME 类型（如 `"video/VP8"`, `"audio/opus"`） |
| `payloadType` | number | RTP 载荷类型（0~127） |
| `clockRate` | number | 采样率（Hz），如 48000 |
| `channels` | number | 声道数（1=单声道, 2=立体声） |
| `sdpFmtpLine` | string | SDP fmtp 参数（如 `"maxplaybackrate=16000"`） |

```js
// 获取 codec 统计
const stats = await peerConnection.getStats();
stats.forEach(report => {
  if (report.type === 'codec') {
    console.log(`Codec: ${report.mimeType}, PT: ${report.payloadType}`);
  }
});
```

## 传输统计 — RTCTransportStats

### 字节与数据包

| 属性 | 说明 |
|------|------|
| `bytesReceived` | 接收的有效载荷字节 |
| `bytesSent` | 发送的有效载荷字节 |
| `packetsReceived` | 接收的数据包数 |
| `packetsSent` | 发送的数据包数 |

### DTLS 状态

| 属性 | 说明 |
|------|------|
| `dtlsState` | DTLS 状态：`new` / `connecting` / `connected` / `closed` / `failed` |
| `dtlsRole` | DTLS 角色：`client` / `server` / `unknown` |

### ICE 状态

| 属性 | 说明 |
|------|------|
| `iceState` | ICE 状态：`new` / `checking` / `connected` / `completed` / `disconnected` / `failed` / `closed` |
| `iceRole` | ICE 角色：`controlling` / `controlled` / `unknown` |

| 属性 | 说明 |
|------|------|

| `selectedCandidatePairChanges` | 候选配对变更次数 |

// 获取传输统计
const stats = await peerConnection.getStats();
stats.forEach(report => {

    console.log(`发送字节: ${report.bytesSent}`);
    console.log(`接收字节: ${report.bytesReceived}`);
  }
});

## 音频源统计 — RTCAudioSourceStats

> 附加到发送者的本地音频轨道统计

| 属性 | 说明 |
|------|------|
| `audioLevel` | 音频电平（0~1，0=静音） |
| `totalAudioEnergy` | 总音频能量（用于计算平均电平） |
| `totalSamplesDuration` | 总样本时长（秒） |
| `trackIdentifier` | 关联的 MediaStreamTrack ID |
| `kind` | 固定为 `"audio"` |

```js
// 计算平均音频电平 (RMS)
const stats = await sender.getStats();
stats.forEach(report => {
  if (report.type === 'media-source' && report.kind === 'audio') {
    const rms = Math.sqrt(report.totalAudioEnergy / report.totalSamplesDuration);
    console.log(`音频 RMS: ${rms.toFixed(4)}`);
    console.log(`当前电平: ${report.audioLevel}`);
  }
});
```

## 完整示例：监控连接质量

```js
async function monitorConnectionQuality(peerConnection) {
  const stats = await peerConnection.getStats();
  
  let quality = {
    // 本地视频接收
    video: { bytes: 0, packets: 0, packetsLost: 0, jitter: 0 },
    // 本地音频接收
    audio: { bytes: 0, packets: 0, packetsLost: 0, jitter: 0 },
    // 远端（用于 RTT）
    remote: { roundTripTime: 0 }
  };
  
  stats.forEach(report => {
    if (report.type === 'inbound-rtp') {
      const media = quality[report.kind];
      media.bytes = report.bytesReceived;
      media.packets = report.packetsReceived;
      media.packetsLost = report.packetsLost;
      media.jitter = report.jitter * 1000; // 转换为 ms
    }
    
    if (report.type === 'remote-inbound-rtp') {
      quality.remote.roundTripTime = report.roundTripTime * 1000;
    }
  });
  
  return quality;
}

// 使用
setInterval(async () => {
  const q = await monitorConnectionQuality(pc);
  console.log(`RTT: ${q.remote.roundTripTime.toFixed(1)}ms`);
  console.log(`视频 丢包: ${q.video.packetsLost}, 抖动: ${q.video.jitter.toFixed(2)}ms`);
}, 2000);
```
