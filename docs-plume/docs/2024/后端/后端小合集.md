## 一、Java 基础篇

### 1.1 位运算

| 运算 | 说明 | 规则 |
| --- | --- | --- |
| `&` 与 | 全1是1 | 两位都为1时结果为1 |
| `\|` 或 | 有1是1 | 两位有一个为1时结果为1 |
| `^` 异或 | 相异为1 | 两位不同时结果为1 |
| `~` 按位取反 | 0变1，1变0 | 单目运算符 |

**移位运算**（int 为 4 字节 32 位，移位 n%32 位）：

```text
<<  (左移)      ：低位补0，相当于乘以2（符号位不变）
>>  (带符号右移)：正数高位补0，负数高位补1
>>> (无符号右移) ：高位补0，相当于除以2（负数是补码移动）
```

**字节序**：
- 大端字节序：高位字节在前，低位字节在后
- 小端字节序：低位字节在前，高位字节在后

### 1.2 集合框架

#### Map 接口

| 实现类 | 线程安全 | 底层结构 | 特点 |
| --- | --- | --- | --- |
| `HashMap` | ❌ | 数组+链表/红黑树 | 无序，k/v 可 null，key 不重复；链化≤6→链表，树化>8 且容量≥64→红黑树；扩容 2 倍 |
| `LinkedHashMap` | ❌ | HashMap + 双向链表 | 有序（添加顺序/访问顺序） |
| `ConcurrentHashMap` | ✅ | 分段锁/Node+CAS | key、value 不可为 null |
| `TreeMap` | ❌ | 红黑树 | 按 key 排序，k 不可为 null |

#### Collection 接口

**List 系列：**

| 实现类 | 线程安全 | 底层结构 | 特点 |
| --- | --- | --- | --- |
| `ArrayList` | ❌ | 数组 | 查询快（索引），增删慢（扩容1.5倍+拷贝）；无参构造初始容量10 |
| `LinkedList` | ❌ | 双向链表 | 增删快（仅调整指针），查询慢（只能头尾遍历） |
| `CopyOnWriteArrayList` | ✅ | 写时复制数组 | 读无锁，写加锁复制 |

**Set 系列：**

| 实现类 | 线程安全 | 底层结构 | 特点 |
| --- | --- | --- | --- |
| `HashSet` | ❌ | HashMap | 无序，值唯一，可 null |
| `LinkedHashSet` | ❌ | LinkedHashMap | 有序 |
| `TreeSet` | ❌ | TreeMap（红黑树） | 按值排序，值不为 null |

### 1.3 面向对象三大特性

| 对比 | 重写 | 重载 |

### 1.5 设计原则

| 原则 | 全称 | 核心思想 |
| --- | --- | --- |
| OCP | 开闭原则 | 对扩展开放，对修改关闭 |
| LSP | 里氏代换原则 | 基类可出现的地方，子类一定可以出现 |
| DIP | 依赖倒转原则 | 针对接口编程，依赖抽象而非具体 |
| ISP | 接口隔离原则 | 多个隔离接口优于单个大接口，降低耦合 |
| DP | 迪米特法则（最少知道） | 实体尽量少与其他实体交互，模块独立 |
| CRP | 合成复用原则 | 尽量使用合成/聚合，而非继承 |

## 二、Lombok 篇

### 2.1 @Builder（建造者模式）

| 属性 | 说明 |
| --- | --- |
| 作用范围 | `TYPE`（类）、`METHOD`（方法）、`CONSTRUCTOR`（构造器） |
| 原理 | 编译时创建内部静态类，有与实体类相同属性的 set 方法，返回 this 实现链式调用 |

**常用属性：**

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `builderMethodName` | `"builder"` | 静态构建器方法名 |
| `buildMethodName` | `"build"` | build 方法名 |
| `builderClassName` | `""` | 内部构建器类名（默认 `类名Builder`） |
| `toBuilder` | `false` | 是否生成 toBuilder() 方法（从现有对象创建 builder） |
| `access` | `AccessLevel.PUBLIC` | 构建器方法的访问级别 |
| `setterPrefix` | `""` | setter 方法前缀 |

**示例：**

```java
@Data
@Builder
public class User {
    private Long id;
    private String name;
    private Integer age;
}

// 链式调用
User user = User.builder()
    .id(1L)
    .name("张三")
    .age(20)
    .build();

// 从现有对象生成新对象（需 toBuilder = true）
@Builder(toBuilder = true)
class User2 { ... }
User2 newUser = oldUser.toBuilder().age(21).build();
```

### 2.2 @SneakyThrows（隐式异常抛出）

| 属性 | 说明 |
| --- | --- |
| 作用范围 | `METHOD`（方法）、`CONSTRUCTOR`（构造器） |
| 原理 | 编译时自动生成 `try{}catch{}` 块，把检查异常包装为运行时异常向上抛出 |
| value 属性 | 默认 `{Throwable.class}`，可指定要捕获的异常类型 |

**对比：**

| 方式 | 代码 |
| --- | --- |
| 手动 try-catch | ```java
public void hhh(User user) {
  try {
    int userId = user.getId();
  } catch (Exception e) {
    throw new RuntimeException(e);
  }
}
``` |
| @SneakyThrows | ```java
@SneakyThrows
public void hhh(User user) {
   int userId = user.getId();
}
``` |

### 3.1 @CrossOrigin（跨域）

| 属性 | 说明 |
| --- | --- |
| 作用范围 | `TYPE`（类）、`METHOD`（方法） |
| 原理 | Spring 拦截器往响应头添加 `Access-Control-Allow-Origin` 等 CORS 头 |

**核心属性：**

| 属性 | 说明 |
| --- | --- |
| `origins` / `value` | 允许的源域名，如 `"http://localhost:8080"`，默认 {} |
| `originPatterns` | 允许的源域名通配符模式，如 `"*.example.com"` |
| `allowedHeaders` | 允许的请求头 |
| `exposedHeaders` | 暴露给客户端的响应头 |
| `methods` | 允许的请求方法（GET/POST/...） |
| `allowCredentials` | 是否允许携带 Cookie（"true"/"false"） |
| `maxAge` | 预检请求缓存时长（秒），默认 -1 |

**跨域解决方案对比：**

| 方案 | 原理 | 限制 |
| --- | --- | --- |
| JSONP | 利用 script 标签无跨域限制 | 仅支持 GET，需服务端配合 |
| CORS | 服务端添加 `Access-Control-*` 响应头 | 标准方案，Spring 原生支持 |
| 服务端代理 | 服务器间不存在跨域，由后端转发请求 | 需额外配置代理 |

### 3.3 日志配置

#### 系统日志 vs 操作日志

| 维度 | 系统日志 | 操作日志 |
| --- | --- | --- |
| 内容 | debug/info/warn/error 程序执行记录 | 用户业务操作行为记录 |
| 受众 | 程序员/运维排查故障 | 管理员/用户回溯操作 |
| 存储 | 文件/日志中心 | 数据库 |

#### 三种实现方案对比

| 方案 | 依赖 | 原理 | 颗粒度 | 能否获取 Body | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| Filter（过滤器） | Servlet 容器 | 函数回调 | URL 级别 | ✅ | 处理请求/响应内容 |
| HandlerInterceptor（拦截器） | SpringMVC | 反射（AOP 思想） | Controller 方法 | ❌ | 登录验证、权限校验（可识别特定注解方法） |
| Spring AOP（切面） | Spring AOP | 动态代理 | 方法级别 | ✅ | 操作日志（可获取参数+返回值+异常） |

#### Spring AOP 操作日志实现

**1. 自定义注解 + 切面：**

```java
// 自定义注解
@Target({ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
public @interface JQHLog {
    String name() default "";      // 功能名称
    String descript() default "";  // 功能描述
}

// 切面（注意实现 Ordered 优先于全局异常处理）
@Component
@Aspect
@Slf4j
public class LogAspect implements Ordered {
    @Override
    public int getOrder() { return 1; } // 返回值越小越先执行

    @Pointcut("@annotation(com.example.JQHLog)")
    public void pointcut() {}

    @Around("pointcut()")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        long beginTime = System.currentTimeMillis();
        Object result = joinPoint.proceed();
        long time = System.currentTimeMillis() - beginTime;

        MethodSignature signature = (MethodSignature) joinPoint.getSignature();
        Method method = signature.getMethod();
        JQHLog anno = method.getAnnotation(JQHLog.class);
        // ... 收集：类名、方法名、参数、IP、URI、耗时等
        return result;
    }
}
```

**2. AOP 五种通知类型：**

| 通知 | 执行时机 | 注解 |
| --- | --- | --- |
| 前置通知 | 目标方法执行之前 | `@Before` |
| 后置通知 | 目标方法执行之后（无论是否异常） | `@After` |
| 返回通知 | 目标方法返回结果之后（可修改返回值） | `@AfterReturning(returning="obj")` |
| 异常通知 | 目标方法抛出异常后 | `@AfterThrowing(throwing="e")` |
| 环绕通知 | 最强大，可控制目标方法是否执行 | `@Around` + `ProceedingJoinPoint.proceed()` |

### 3.4 @RestControllerAdvice（全局异常处理）

**标准三件套：状态码枚举 + 统一返回类 + 自定义异常 + 全局异常处理器**

```java
// 1. 状态码枚举
public enum ResultCode {
    SUCCESS(200, "操作成功!"),
    FAILURE(201, "操作失败"),
    ERROR(500, "系统异常，请稍后重试"),
    PARAM_ERROR(1000, "参数异常"),
    INVALID_TOKEN(2001, "访问令牌不合法"),
    USERNAME_OR_PASSWORD_ERROR(2003, "用户名或密码错误");

    private final int code;
    private final String message;
    ResultCode(int code, String message) { this.code = code; this.message = message; }
    public int getCode() { return code; }
    public String getMessage() { return message; }
}
```

```java
// 2. 统一返回类
@Data
public class Result<T> implements Serializable {
    private Integer code;
    private String message;
    private T data;

    public static <T> Result<T> success() { return new Result<>(200, "操作成功!"); }
    public static <T> Result<T> success(T data) { return new Result<>(200, "操作成功!", data); }
    public static <T> Result<T> fail(Integer code, String message) { return new Result<>(code, message); }
    public static <T> Result<T> error() { return new Result<>(500, "系统异常，请稍后重试"); }
}
```

```java
// 3. 自定义异常
public class CustomException extends RuntimeException {
    protected Integer code;
    public CustomException(Integer code, String message) { super(message); this.code = code; }
    public Integer getCode() { return code; }
}
```

```java
// 4. 全局异常处理器
@Slf4j
@RestControllerAdvice
public class GlobalException {
    @ExceptionHandler(value = CustomException.class)
    public Result<Void> customExceptionHandler(CustomException e) {
        return Result.fail(e.getCode(), e.getMessage());
    }
    @ExceptionHandler(Exception.class)
    public Result<Void> exceptionHandler(Exception e) {
        log.error("全局异常信息 ex={}", e.getMessage(), e);
        return Result.error();
    }
}
```

### 3.5 Bean 注入方式

| 方式 | 来源包 | 作用位置 | 特点 |
| --- | --- | --- | --- |
| `@Resource` | `javax.annotation.Resource` | 字段、方法、构造函数 | 可按名称匹配注入；找不到抛异常 |
| `@Autowired` | `org.springframework.beans.factory.annotation.Autowired` | 字段、方法、构造函数 | 按类型匹配；找不到为 null |
| `private final` + 构造函数 | Spring Boot 原生推荐 | 构造函数参数 | 注入不可变依赖，确保安全性和线程安全性（推荐） |

**推荐写法（构造函数注入，无需 @Autowired）：**

```java
@Service
public class UserService {
    private final UserMapper userMapper;   // final 保证不可变
    private final RoleService roleService;

    // Spring 4.3+ 单构造函数可省略 @Autowired
    public UserService(UserMapper userMapper, RoleService roleService) {
        this.userMapper = userMapper;
        this.roleService = roleService;
    }
}
```

### 3.6 参数校验（@Valid + @Validated）

#### 依赖

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>

#### @Valid vs @Validated

| 维度 | @Valid（JSR-303 标准） | @Validated（Spring 扩展） |
| --- | --- | --- |
| 来源 | `javax.validation.Valid` | `org.springframework.validation.annotation.Validated` |
| 使用位置 | 方法、方法参数、成员属性（字段） | 类、方法、方法参数 |
| 嵌套校验 | ✅ 直接在字段上标注 `@Valid` | ✅ 可配合 `@Valid` 实现 |
| 分组校验 | ❌ | ✅ `groups` 属性 |
| 分组顺序 | ❌ | ✅ `@GroupSequence` |

#### 常用校验注解

| 注解 | 作用 | 支持类型 |
| --- | --- | --- |
| `@NotNull` | 非 null | 所有类型 |
| `@NotBlank` | 非 null 且 trim 后长度>0 | String |
| `@NotEmpty` | 非 null 且长度>0 | CharSequence/Collection/Map/Array |
| `@Min`/`@Max` | 数字最小/最大值 | 数字类型 |
| `@Size(min,max)` | 字符/集合长度范围 | String/Collection/Array |
| `@Pattern(regexp)` | 正则匹配 | String |
| `@Email` | 邮箱格式 | String |
| `@Future`/`@Past` | 未来/过去日期 | 日期时间类型 |
| `@Positive`/`@Negative` | 正/负数 | 数字类型 |
| `@AssertTrue`/`@AssertFalse` | 必须 true/false | boolean |

#### 嵌套校验示例

```java

@RestController
public class TestController {
    @PostMapping("/userInfo")
    public Result userInfo(@Valid @RequestBody Team team) { return Result.success(team); }

#### 分组校验

```java
// 1. 定义分组接口
public interface MyValidGroup {
    interface SaveDraft { }   // 保存草稿
    interface Submit { }      // 提交表单
    interface Update { }      // 更新数据
}

// 2. DTO 中指定 groups
@Data
public class Project {
    @NotBlank(message = "ID不能为空", groups = {MyValidGroup.Update.class})
    private String id;

    @NotBlank(message = "项目老大不能为空",
        groups = {MyValidGroup.SaveDraft.class, MyValidGroup.Submit.class, MyValidGroup.Update.class})
    private String leader;

    @NotBlank   // 不指定 groups 属于 Default.class 默认分组
    private String strValue;
}

// 3. Controller 中激活指定分组
@PostMapping("/submit")
public Result submit(@Validated(value = {MyValidGroup.Submit.class, Default.class})
                     @RequestBody Project project) {
    return Result.success(project);
}
```

#### 快速失败 + 校验异常处理

```java
// 快速失败配置（遇到第一个校验失败即返回）
@Configuration
public class ValidConfig {
    @Bean
    public Validator validator() {
        return Validation.byProvider(HibernateValidator.class)
            .configure()
            .failFast(true)
            .buildValidatorFactory()
            .getValidator();
    }
}

// 全局异常中捕获校验异常
@ExceptionHandler(value = MethodArgumentNotValidException.class)
public Result dealValidException(MethodArgumentNotValidException e) {
    String message = e.getBindingResult().getAllErrors().stream()
        .map(ObjectError::getDefaultMessage)
        .collect(Collectors.joining(";"));
    return Result.fail(1000, message);
}

### 3.7 国际化（I18n）

#### 核心概念

| 类 | 作用 |
| --- | --- |
| `java.util.Locale` | 本地化语言对象，包含语言+国家代码 |
| `MessageSource` | 根据 Locale + code 获取国际化消息 |
| `LocaleResolver` | 解析当前请求使用的 Locale（从 URL/Header/Session 等） |

#### 完整实现步骤

**1. 国际化资源文件 `resources/i18n/messages_xx_XX.properties`**

| 文件 | 说明 |
| --- | --- |
| `messages.properties` | 默认（中文） |
| `messages_zh_CN.properties` | 中文简体 |
| `messages_en_US.properties` | 英文 |

**2. yml 配置**

```yaml
spring:
  messages:
    basename: i18n/messages
    encoding: UTF-8
```

**3. 自定义 MessageSource（支持从数据库+配置文件加载）**

```java
@Component("messageSource")
public class CustomMessageSource extends AbstractMessageSource implements InitializingBean {
    @Resource private I18nMessageMapper i18nMessageMapper;
    private static final Map<String, Map<String, String>> LOCAL_CACHE = new ConcurrentHashMap<>();

    @Override
    public void afterPropertiesSet() { this.reload(); }

    public void reload() {
        LOCAL_CACHE.clear();
        LOCAL_CACHE.putAll(this.loadAllMessageResources());
    }

    private Map<String, Map<String, String>> loadAllMessageResources() {
        // 1. 从数据库加载 i18n_message 表
        List<I18nMessage> dbList = i18nMessageMapper.selectAllList();
        Map<String, Map<String, String>> localeMsgMap = Optional.ofNullable(dbList)
            .orElseGet(ArrayList::new).stream()
            .collect(Collectors.groupingBy(I18nMessage::getLocale,
                Collectors.toMap(I18nMessage::getCode, I18nMessage::getMessage)));
        // 2. 合并 properties 文件（文件覆盖数据库）
        localeMsgMap.keySet().stream().map(Locale::new).forEach(locale -> {
            ResourceBundle bundle = ResourceBundle.getBundle("i18n/messages", locale);
            Map<String, String> fileMap = bundle.keySet().stream()
                .collect(Collectors.toMap(Function.identity(), bundle::getString));
            Map<String, String> merged = localeMsgMap.get(locale.getLanguage());
            merged.putAll(fileMap);
            localeMsgMap.put(locale.getLanguage(), merged);
        });
        return localeMsgMap;
    }

    private String getSourceFromCache(String code, Locale locale) {
        String lang = ObjectUtils.isEmpty(locale)
            ? LocaleContextHolder.getLocale().getLanguage()
            : locale.getLanguage();
        return Optional.ofNullable(LOCAL_CACHE.get(lang))
            .map(m -> m.get(code)).orElse(code);
    }

    @Override
    protected MessageFormat resolveCode(String code, Locale locale) {
        return new MessageFormat(getSourceFromCache(code, locale), locale);
    }
    @Override
    protected String resolveCodeWithoutArguments(String code, Locale locale) {
        return getSourceFromCache(code, locale);
    }
}
```

**4. 自定义 LocaleResolver（URL 参数 lang / Header lang 优先）**

```java
@Component
public class CustomLocaleResolver implements LocaleResolver {
    @Override
    public Locale resolveLocale(HttpServletRequest request) {
        String langParam = request.getParameter("lang");   // URL 参数优先
        String langHeader = request.getHeader("lang");     // Header 其次
        return Optional.ofNullable(langParam)
            .map(l -> parseLocale(l))
            .orElseGet(() -> Optional.ofNullable(langHeader)
                .map(h -> parseLocale(h.replaceAll("\"", "")))
                .orElse(Locale.getDefault()));
    }
    private Locale parseLocale(String l) {
        String[] split = l.split("_");
        return new Locale(split[0], split.length > 1 ? split[1] : "");
    }
    @Override
    public void setLocale(HttpServletRequest req, HttpServletResponse res, Locale locale) {}
}
```

**5. 工具类封装**

```java
@Component
public class I18nMessageUtil {
    private static MessageSource messageSource;

    @Autowired
    public I18nMessageUtil(MessageSource messageSource) {
        I18nMessageUtil.messageSource = messageSource;
    }

    public static String getMessage(String code) {
        return getMessage(code, null, "");
    }
    public static String getMessage(String code, Object[] args) {
        return getMessage(code, args, "");
    }
    public static String getMessage(String code, Object[] args, String defaultMessage) {
        return messageSource.getMessage(code, args, defaultMessage, LocaleContextHolder.getLocale());
    }
}
