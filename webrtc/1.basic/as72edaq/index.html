WebRTC 错误处理完全指南

RTCError 和 RTCErrorEvent — 错误类型与事件

概述

WebRTC 错误处理涉及两个紧密相关的接口：

接口职责
RTCError包含具体的错误类型和详情
RTCErrorEvent错误事件，携带着 RTCError 对象
RTCErrorEvent
    │
    └── error: RTCError
              │
              ├── errorDetail: "sdp-syntax-error" | "dtls-failure" | ...
              ├── sdpLineNumber: number
              ├── sctpCauseCode: number
              ├── receivedAlert: number
              └── sentAlert: number

RTCError

WebRTC 错误接口

构造函数

new RTCError(options)
new RTCError(options, message)

options 参数：

属性类型说明
errorDetailstring必填，WebRTC 错误类型
receivedAlertnumberDTLS 错误时接收的告警（可选）
sctpCauseCodenumberSCTP 错误原因码（可选）
sdpLineNumbernumberSDP 语法错误行号（可选）

errorDetail — 错误类型

返回 WebRTC 特定错误类型的字符串。

error.errorDetail  // string

可能的值：

值说明相关属性
data-channel-failureRTCDataChannel 连接失败-
dtls-failureDTLS 连接协商失败或连接终止receivedAlert, sentAlert
fingerprint-failure远程证书与 SDP 中的指纹不匹配-
hardware-encoder-error硬件编码器不支持给定配置-
hardware-encoder-not-available硬件编码器资源不可用-
sctp-failureSCTP 协商失败或连接终止sctpCauseCode
sdp-syntax-errorSDP 语法无效sdpLineNumber

属性

receivedAlert — 接收的 DTLS 告警

返回从远程对等端接收的致命 DTLS 错误号。

error.receivedAlert  // number | null

仅在 errorDetail 为 dtls-failure 时有效。

sentAlert — 发送的 DTLS 告警

返回发送给远程对等端的 DTLS 错误告警号。

error.sentAlert  // number | null

仅在 errorDetail 为 dtls-failure 时有效。

sctpCauseCode — SCTP 原因码

返回 SCTP 协商失败的原因码。

error.sctpCauseCode  // number | null

仅在 errorDetail 为 sctp-failure 时有效。 标准 SCTP 错误原因码（1-13）定义在 RFC 4960 中。

sdpLineNumber — SDP 行号

返回 SDP 语法错误发生的行号。

error.sdpLineNumber  // number | null

仅在 errorDetail 为 sdp-syntax-error 时有效。 行号从 1 开始计数。

RTCErrorEvent

WebRTC 错误事件接口

构造函数

new RTCErrorEvent(type, options)

参数：

参数类型说明
typestring事件名称（通常为 "error"）
optionsobject包含 error 属性（必填）及其他 Event 属性

options 属性：

属性类型说明
errorRTCError描述错误原因和位置的 RTCError 对象
bubblesboolean是否冒泡（继承自 Event）
cancelableboolean是否可取消（继承自 Event）

属性

error — RTC 错误对象

返回包含 WebRTC 特定错误详情的 RTCError 对象。

event.error  // RTCError

触发源

RTCErrorEvent 由以下对象触发：

对象事件
RTCDataChannelerror
RTCDtlsTransporterror

注意：RTCPeerConnectionIceErrorEvent 是独立的错误事件，用于 ICE 协商错误。

使用示例

基本错误处理

dataChannel.addEventListener("error", (event) => {
  let error = event.error; // event.error 是 RTCError

  if (error.errorDetail === "sdp-syntax-error") {
    // SDP 语法错误
    let errLine = error.sdpLineNumber;
    let errMessage = error.message;
    console.log(`SDP 第 ${errLine} 行语法错误: ${errMessage}`);
  } else if (error.errorDetail === "dtls-failure") {
    // DTLS 失败
    console.log(`DTLS 错误: 接收告警=${error.receivedAlert}, 发送告警=${error.sentAlert}`);
  } else if (error.errorDetail === "sctp-failure") {
    // SCTP 失败
    console.log(`SCTP 错误原因码: ${error.sctpCauseCode}`);
  } else {
    // 其他错误，终止连接
    terminateMyConnection();
  }
});

使用 onerror 处理器

dataChannel.onerror = (event) => {
  let error = event.error;
  console.error('DataChannel 错误:', error.message);
};

手动创建事件

// 创建 RTCError
const rtcError = new RTCError(
  {
    errorDetail: "sdp-syntax-error",
    sdpLineNumber: 42,
  },
  "SDP syntax error on line 42"
);

// 创建 RTCErrorEvent
const event = new RTCErrorEvent("error", {
  error: rtcError,
  bubbles: true,
  cancelable: false,
});
