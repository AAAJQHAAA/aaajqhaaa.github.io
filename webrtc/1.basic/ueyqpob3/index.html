WebRTC DTMF 完全指南

约 649 字大约 2 分钟

2026-08-18

双音多频信号 — 与传统电话网络交互

概述

DTMF（Dual-Tone Multi-Frequency）允许 WebRTC 客户端与传统电话网络（PSTN）或 VoIP 服务交互。

限制：DTMF 不能在两个 WebRTC 设备之间使用，因为 WebRTC 没有接收 DTMF 码的机制。

核心接口

接口职责
RTCDTMFSender发送 DTMF 音调
RTCDTMFToneChangeEvent音调变化事件

工作流程

RTCDTMFSender
    │
    ├── insertDTMF(tones)     // 发送 DTMF 序列
    ├── toneBuffer             // 待发送的音调队列
    └── ontonechange = (ev)   // 监听此事件
              │
              └─→ RTCDTMFToneChangeEvent
                      │
                      └── tone: "1" | "2" | "" (结束)

RTCDTMFSender

发送 DTMF 音调

获取方式

const dtmfSender = audioTrackSender.dtmf;

属性

canInsertDTMF

是否支持 DTMF。

dtmfSender.canInsertDTMF  // boolean

toneBuffer

当前排队待发送的 DTMF 音调列表（已播放的不包含在内）。

dtmfSender.toneBuffer  // string

格式：

  • 数字：0-9
  • 字母：A-D（大写）
  • 特殊键：#、*
  • 逗号：, 表示暂停 2 秒（如 "12,34" 表示发 1、2，暂停 2 秒，再发 3、4）

方法

insertDTMF()

发送 DTMF 音调到远程对等端。

dtmfSender.insertDTMF(tones);
dtmfSender.insertDTMF(tones, duration);
dtmfSender.insertDTMF(tones, duration, interToneGap);

参数：

参数类型默认值说明
tonesstring-DTMF 字符序列
durationnumber100ms每个音调的持续时间（40~6000ms）
interToneGapnumber70ms音调之间的间隔（最小 30ms）

异常：

  • InvalidStateError：轨道已停止或处于只读/非活动状态
  • InvalidCharacterError：包含无效 DTMF 字符

RTCDTMFToneChangeEvent

音调变化事件

构造函数

new RTCDTMFToneChangeEvent(type)
new RTCDTMFToneChangeEvent(type, options)

属性

tone

当前播放的 DTMF 字符，或空字符串表示所有音调已播放完毕。

event.tone  // string

返回值：

值含义
"0"-"9"电话按键数字
"A"-"D"DTMF 标准键
"#" / "*"特殊键
""所有音调已播放完毕

DTMF 字符表

字符说明
0-9电话按键数字
A-DDTMF 标准键（大多数电话上没有）
#井号键
*星号键
,暂停 2 秒

使用示例

基本用法

// 获取 DTMF 发送器
const dtmfSender = sender.dtmf;

// 检查是否支持 DTMF
if (dtmfSender.canInsertDTMF) {
  // 发送 DTMF：1、2，暂停 2 秒，然后 3、4
  dtmfSender.insertDTMF('12,34', 500, 50);
  
  // 监听音调变化
  dtmfSender.ontonechange = (event) => {
    console.log('当前音调:', event.tone || '<结束>');
  };
}

实时显示音调

dtmfSender.ontonechange = (ev) => {
  let tone = ev.tone;
  if (tone === "") {
    tone = "<none>";
  }
  document.getElementById("playingTone").innerText = tone;
};

追加音调

// 追加新的音调到现有队列
const currentTones = dtmfSender.toneBuffer;
dtmfSender.insertDTMF(currentTones + '56');

取消发送

// 清空缓冲区，取消所有待发送的音调
dtmfSender.insertDTMF('');
