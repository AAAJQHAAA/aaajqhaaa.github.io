WebRTC-编码转换

约 517 字大约 2 分钟

2026-08-15

概述

  • 功能不太成熟，实际没啥用，只是因为它是 WebRTC 规范的一部分才会保留

WebRTC 编码转换（Encoded Transforms）允许在 WebRTC 管道中修改编码后的音视频帧。

典型应用

应用说明
端到端加密第三方代码对帧进行加密/解密
滤镜修改视频画面效果
转码转换编码格式

工作原理

主线程                           Worker
  │                                │
  │ RTCRtpScriptTransform ──────→  │
  │                                │
  │                          transform()
  │                                │
  │   readable ←─── 编码帧 ─── writable
  │                                │
  │    (输入)        处理        (输出)

核心概念

接口作用
RTCRtpScriptTransform主线程创建，指定 worker
RTCRtpScriptTransformerworker 中访问，输入输出流
RTCRtpSender.transform添加到发送管道
RTCRtpReceiver.transform添加到接收管道

发送端添加转换

// 获取视频轨道
const stream = await navigator.mediaDevices.getUserMedia({ video: true });
const [track] = stream.getTracks();
const sender = peerConnection.addTrack(track, stream);

// 创建 worker 并添加转换
const worker = new Worker("worker.js");
sender.transform = new RTCRtpScriptTransform(worker, {
  name: "senderTransform"
});

接收端添加转换

// 收到轨道时添加转换
peerConnection.ontrack = (event) => {
  const worker = new Worker("worker.js");
  event.receiver.transform = new RTCRtpScriptTransform(worker, {
    name: "receiverTransform"
  });
};

Worker 实现

addEventListener("rtctransform", (event) => {
  const transform = new TransformStream({
    async transform(encodedFrame, controller) {
      // encodedFrame 是 RTCEncodedVideoFrame 或 RTCEncodedAudioFrame
      
      // 修改帧数据...
      
      controller.enqueue(encodedFrame);
    }
  });
  
  event.transformer.readable
    .pipeThrough(transform)
    .pipeTo(event.transformer.writable);
});

关键帧（Key Frame）处理

问题

视频编码通常发送：

  • 关键帧（Key Frame） - 完整画面
  • Delta 帧 - 只有变化部分

新用户加入会议时，需要等待第一个关键帧才能显示画面。

解决方案

// 在 worker 中请求生成新关键帧
event.transformer.options.port.onmessage = (event) => {
  const { rid, key } = event.data;
  
  // 让编码器生成关键帧
  event.transformer.generateKeyFrame(rid);
};

// 接收端可以请求发送端发关键帧
transformer.sendKeyFrameRequest();

与主线程通信

通过 MessageChannel 在主线程和 worker 之间传递消息：

// 主线程
const channel = new MessageChannel();
sender.transform = new RTCRtpScriptTransform(worker, {
  port: channel.port2
}, [channel.port2]);

channel.port1.postMessage({ cmd: "setKey", key: "..." });

// Worker
event.transformer.options.port.onmessage = (event) => {
  console.log(event.data);
};

浏览器支持

const supportsEncodedTransforms =
  window.RTCRtpSender && "transform" in RTCRtpSender.prototype;

完整流程图

1. 主线程创建 Worker
         ↓
2. 创建 RTCRtpScriptTransform
         ↓
3. 赋值给 sender.transform 或 receiver.transform
         ↓
4. Worker 收到 rtctransform 事件
         ↓
5. 建立管道：readable → TransformStream → writable
         ↓
6. 编码帧流经 worker，可以修改或加密
