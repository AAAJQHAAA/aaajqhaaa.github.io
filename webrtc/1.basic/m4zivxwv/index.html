WebRTC 会话与身份完全指南

SDP 会话描述、身份断言与证书

概述

模块五包含三个接口，用于 WebRTC 连接的安全和协商：

接口职责
RTCSessionDescriptionSDP 会话描述，交换连接配置
RTCIdentityAssertion远程对等端身份验证
RTCCertificateDTLS 证书，用于加密连接
协商流程：
                    SDP 交换                       身份验证
┌─────────┐                         ┌─────────┐
│  本地端  │ ════════════════════════│  远端   │
│         │    setLocalDescription  │         │
│         │ ←───────────────────────│         │
│         │    setRemoteDescription │         │
└─────────┘                         └─────────┘

证书流程：
生成证书 → 交换指纹 → DTLS握手 → 信任建立

RTCSessionDescription

SDP 会话描述接口

构造函数

已废弃 — 推荐使用普通对象

// 已废弃（但仍可用）
new RTCSessionDescription({ type: "offer", sdp: "..." })

// 推荐方式
{ type: "offer", sdp: "..." }

属性

type — 描述类型

description.type  // "offer" | "answer" | "pranswer" | "rollback"
类型说明
offer发起方的初始配置请求
answer响应方的应答
pranswer部分临时的应答
rollback回滚到无协商状态

sdp — SDP 描述

SDP 格式的会话描述字符串。

description.sdp  // string

方法

toJSON()

返回 JSON 格式描述。

description.toJSON()  // { type: string, sdp: string }

SDP 结构示例

v=0                                    // 版本
o=- 1234567890 2 IN IP4 127.0.0.1     // 会话 Origin
s=-                                    // 会话名
t=0 0                                  // 时间
m=video 5004 RTP/AVP 96               // 媒体描述 (video)
c=IN IP4 0.0.0.0                      // 连接信息
a=rtpmap:96 VP8/90000                 // RTP 映射
a=fmtp:96 profile-level-id=42e01e     // 格式参数

SDP 关键内容：

  • 支持的 codec（opus、vp9...）
  • 媒体类型（audio/video）
  • 候选候选人列表
  • 传输参数

完整协商流程

const pc = new RTCPeerConnection();

signalingChannel.onmessage = async (evt) => {
  const message = JSON.parse(evt.data);
  
  if (message.type === "offer") {
    // 收到 offer
    await pc.setRemoteDescription(message);
    const answer = await pc.createAnswer();
    await pc.setLocalDescription(answer);
    signalingChannel.send(answer);
    
  } else if (message.type === "answer") {
    // 收到 answer
    await pc.setRemoteDescription(message);
    
  } else if (message.candidate) {
    // 收到 ICE 候选者
    await pc.addIceCandidate(message);
  }
};

// 创建 offer
const offer = await pc.createOffer();
await pc.setLocalDescription(offer);
signalingChannel.send(pc.localDescription);

属性/方法速查

属性/方法类型说明
type属性描述类型
sdp属性SDP 描述字符串
toJSON()方法转换为 JSON

RTCIdentityAssertion

WebRTC 远程对等端身份断言接口

概述

RTCIdentityAssertion 表示当前连接的远程对等端身份。

  • 未设置或验证时返回 null
  • 一旦设置不可更改

属性

idp — 身份提供商域名

身份提供商（IdP）的域名。

assertion.idp  // string

name — 对等端身份名称

验证后的对等端身份，格式为电子邮件地址格式。

assertion.name  // string (如 "user@example.com")

身份验证流程

┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   本地端      │     │     IdP      │     │   远程端      │
└──────┬───────┘     └──────┬───────┘     └──────┬───────┘
       │                    │                    │
       │────请求身份───────→│                    │
       │                    │────验证身份───────→│
       │                    │←───身份断言───────│
       │←──验证完成────────│                    │

使用示例

const pc = new RTCPeerConnection();

async function logPeerIdentity() {
  try {
    const identity = await pc.peerIdentity;
    console.log(`IdP 域名: ${identity.idp}`);
    console.log(`对等端名称: ${identity.name}`);
  } catch (err) {
    console.error("无法验证对等端身份:", err);
  }
}

logPeerIdentity();

属性速查

属性类型说明
idpstring身份提供商域名
namestring对等端身份名称

RTCCertificate

WebRTC DTLS 证书接口

概述

RTCCertificate 代表 WebRTC 连接用于身份验证的证书。

特点：

  • 可序列化对象，可用 structuredClone() 克隆
  • 可在 Worker 间通过 postMessage() 传递

用途：

  • 存储和重用证书以建立信任关系
  • 通过证书指纹识别用户
  • 在 SDP 交换期间自动交换

属性

expires — 过期时间

证书的过期日期。

cert.expires  // Unix 时间戳（毫秒）
配置值
默认值30 天（2592000000 毫秒）
最大限制365 天（31536000000 毫秒）

方法

getFingerprints() — 获取证书指纹

const fingerprints = cert.getFingerprints()

返回值数组：

属性说明
algorithm哈希算法："sha-1", "sha-224", "sha-256", "sha-384", "sha-512"
value小写十六进制字符串的指纹值

证书生命周期

生成证书 → 交换指纹 → DTLS 握手验证 → 信任建立
    ↓
存储到 IndexedDB（可选，重用时读取）
    ↓
过期后自动重新生成

使用示例

生成证书

RTCPeerConnection.generateCertificate({
  name: "RSASSA-PKCS1-v1_5",
  hash: "SHA-256",
  modulusLength: 2048,
  publicExponent: new Uint8Array([1, 0, 1]),
}).then((cert) => {
  const pc = new RTCPeerConnection({ certificates: [cert] });
  console.log(cert.expires); // 2592000000 (30天)
});

获取指纹

const fingerprints = cert.getFingerprints();
fingerprints.forEach(fp => {
  console.log(`${fp.algorithm}: ${fp.value}`);
});

属性/方法类型说明
